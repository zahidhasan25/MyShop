# MyShop

## Project overview

MyShop is an online shop web application. It displays a small product catalog with images, prices and categories, and lets shoppers search products, add them to a cart, adjust quantities, and complete a checkout form.

## Main technologies

- React (JavaScript, JSX)
- Vite
- Tailwind CSS
- HTML and CSS

## Main features

- Product catalog with product images, prices, previous prices and categories (Electronics, Fashion and Beauty)
- Category filtering and product search
- Shopping cart with add, remove and quantity controls
- Checkout form that collects the customer's name, phone number and address, with an order confirmation state

## Dependencies

- react and react-dom
- @tailwindcss/vite and tailwindcss

Development dependencies include @vitejs/plugin-react, @types/react, @types/react-dom, oxlint and vite.

## How to run locally

Prerequisites: Node.js, npm and Git.

```bash
git clone https://github.com/zahidhasan25/MyShop.git
cd MyShop
npm install
npm run dev
```

Then open the local development URL shown in the terminal. To create a production build, run `npm run build`; to preview it locally, run `npm run preview`.
